# Dext 0.1.2

0.1.2 replaces the `.dx` language with real TypeScript: Code mode now runs in a long-lived Node kernel, the composer completes the generated `dext` API, and a failed run resumes at the call boundary. The release also renames several settings keys, applies Agent patches automatically, adds Pi and DeepSeek Harness backends, and moves conversation history into files. Upgrading needs the `.dx` migration script and a `settings.json` pass.

## ✨ Highlights

- Code mode runs real TypeScript in a Node kernel — migrate every `.dx` API with `node scripts/migrateDxToTs.mjs`.
- Several names changed at once: `dext.apiDirs`, `dext.skillDirs`, `dext.plan.directory`, the API entry function name and `agent()` patches.
- Pi and DeepSeek Harness are now first-class Agent backends, and conversation history moved to one file per conversation.

## 💥 Breaking changes

- **`.dx` sources are no longer recognised** — run `node scripts/migrateDxToTs.mjs` to convert them to `.ts`, then point the imports at the new module.
- **An API entry function must be named after its file and `main` is ignored** — rename `export async function main` to the file's own name in every API file and update the imports that referenced `main`.
- **`chat`, `print`, `text`, `code` and `patch` are gone and the result kinds dropped from 14 to 9** — replace `print(text)` with `console.log(text)` and drop the removed result kinds from your workflow results.
- **`agent()` applies its patch before returning, and the Accept/Reject cards, diff views and `dext.diff.defaultView` are gone** — delete `dext.diff.defaultView` from `settings.json` and pass `agent(patch=false)` where you still want text only.
- **`dext.apiDirs`, `dext.skillDirs` and `dext.plan.directory` are renamed** — replace them with `dext.apiDirectories`, `dext.skillDirectories` and `dext.planDirectory` in `settings.json`.
- **Source-file inline completion is removed with its settings, evaluation commands and stored feedback** — delete every `dext.completion*` entry from `settings.json`.
- **`ui.choose` and `UiChoiceResult` are removed** — replace each call with `ui.radio`, `ui.checkbox` or `ui.select`; `ui.alert` and `ui.form` (which takes `actions`) are the new calls.
- **`dext.viewMcp` is now `dext.viewResources` and MCP tools moved under Resources** — rename the key in `settings.json` and open MCP tools from the Resources page.
- **DeepSeek Harness 0.1.x presets are no longer supported** — after **Manage presets → Refresh presets**, replace the presets in `$DSH_HOME/.agent-presets` with app-created ones.

## 🚀 New features

- Code mode runs real TypeScript in a long-lived Node child process; `dext.workflow.maxConcurrency` caps concurrent API calls and a failed run resumes at the call boundary while the call's fingerprint still matches.
- The composer brings TypeScript completion, hover, diagnostics and go to definition to Code mode, and **Dext: View APIs** lists the Node and JavaScript reference generated from `.dext/api/dext.d.ts`.
- `template(input, source, values)` renders text from a Dext template whose front matter declares its fields, so no section can be added or reordered, and it writes nothing.
- Pi is an Agent backend: it runs packages installed with `pi install`, picks them per conversation in the **Plugins** row, exposes `dext_fetch` and `dext_submit_result`, and drives a Plan's Todo panel through `dext_update_todos`.
- DeepSeek Harness desktop starts through its own launcher with `--expose-internals`, lists presets from `presets/*.patch.yml`, and merges the app's models from `cordis.patch.yml`.
- Conversation history lives in one file per conversation under `<storageUri>/conversation-history/`, keeps truncated output in overflow files and prunes stale entries.
- Resources groups every category by directory, keeps a hidden Skill installed through `dext.hiddenSkills`, files MCP tools under **MCP**, searches `dext.mcpDirectories` and shows MCP image results.
- Skill packs import from a GitHub release or a bare repository URL, **Update Skill pack** reports added or removed skills, and variants resolve per Agent.
- A settled question card keeps every option, marks the picked rows and accepts a multi-select answer, while `ui.alert` and `ui.form` take explicit `actions`.
- A Plan execution continues across Agent turns with round checkpoints and a separate final verification, and live and restored history show incomplete, blocked and user-stopped outcomes.
- A screenshot annotation tab zooms like a picture viewer with **Fit**, **1:1**, pixel size and **Hide annotations**, and an image can be annotated before it is sent.
- `git.commit` makes one Conventional Commit per feature, `release.audit`, `release.changelog`, `release.notes` and `docs.sync` ship with their rules, and `echo: true` shows a Code call's result in Output.

## 🐛 Fixes

- A stdio MCP server that ignores SIGTERM is force-killed, and MCP manifests and this session's image cache are read within a fixed budget.
- Cancelling a turn stops the whole CLI process group, and the memory of completed tool ids is capped.
- A question card accepts multiple answers, and a known option label counts as a picked answer.
- Ctrl+C stays with VS Code wherever VS Code already copies, and files copied by `dext.copyFilePathWithFiles` remain pasteable in Explorer.
- An unreadable conversation file is skipped instead of failing activation, and another window's writes are re-read before history is mutated.
- Multi-megabyte Agent result frames are accepted over the bridges, and the output a CLI stream accumulates is bounded.
- A Skill pack import no longer fails on JavaScript support files that contain a NUL byte.
- The terminal timeout setting matches runtime behaviour: 120,000 ms by default, 600,000 ms maximum, and an invalid value falls back to the default.

## 📝 Notes

- Dext requires VS Code 1.106 or newer, and it now defaults to the Secondary Side Bar while preserving customized view locations.
- Dext is released under the MIT License; `COMMERCIAL-LICENSING.md` is removed and copies already distributed keep their original terms.
- Commit the generated `.dext/api/dext.d.ts`, `.dext/tsconfig.json` and `.dext/package.json`; an API reload rewrites them together with `@types/node`.
- `dext.history.maxOutputLength` now defaults to `64000`, and history is imported once from the `dext.history*` settings.
- A tool call that never reports a result ends the turn after thirty minutes, while an active Codex, Claude or Harness turn keeps running past one hour.
- The **Output Language** setting also applies to Code mode `agent()` and `ask()` calls, and machine-readable output is never translated.
- A new turn starts with **Process** collapsed, keeps the live `Thinking for …` duration with token and command counts, and Harness adds `12k/1M context`.

## ✨ 亮点

- Code mode 改为在 Node 内核里运行真正的 TypeScript —— 用 `node scripts/migrateDxToTs.mjs` 迁移所有 `.dx` API。
- 多处名称同时改变：`dext.apiDirs`、`dext.skillDirs`、`dext.plan.directory`、API 入口函数名，以及 `agent()` 的 patch 行为。
- Pi 与 DeepSeek Harness 成为一等 Agent 后端，会话历史改为每个会话一个文件。

## 💥 破坏性变更

- **不再识别 `.dx` 源文件** — 运行 `node scripts/migrateDxToTs.mjs` 转成 `.ts`，再把导入指向新的模块。
- **API 入口函数必须与文件名同名，`main` 不再被识别** — 把每个 API 文件里的 `export async function main` 改成文件自身的名字，并更新引用 `main` 的导入。
- **`chat`、`print`、`text`、`code`、`patch` 被移除，结果类型从 14 种减到 9 种** — 把 `print(text)` 换成 `console.log(text)`，并从工作流结果里删掉被移除的类型。
- **`agent()` 在返回前直接应用 patch，Accept/Reject 卡片、diff 视图与 `dext.diff.defaultView` 一起消失** — 从 `settings.json` 删除 `dext.diff.defaultView`；仍只要文本时传 `agent(patch=false)`。
- **`dext.apiDirs`、`dext.skillDirs`、`dext.plan.directory` 改名** — 在 `settings.json` 里分别替换为 `dext.apiDirectories`、`dext.skillDirectories`、`dext.planDirectory`。
- **源码内联补全连同其设置、评测命令与已存反馈一并移除** — 删除 `settings.json` 里所有 `dext.completion*` 条目。
- **`ui.choose` 与 `UiChoiceResult` 被移除** — 把每个调用换成 `ui.radio`、`ui.checkbox` 或 `ui.select`；新接口是 `ui.alert` 和接收 `actions` 的 `ui.form`。
- **`dext.viewMcp` 变为 `dext.viewResources`，MCP 工具归入 Resources** — 在 `settings.json` 里改名，并从 Resources 页打开 MCP 工具。
- **不再支持 DeepSeek Harness 0.1.x 预设** — 在 **Manage presets → Refresh presets** 之后，把 `$DSH_HOME/.agent-presets` 里的预设换成应用内创建的版本。

## 🚀 新功能

- Code mode 在常驻的 Node 子进程里运行真正的 TypeScript；`dext.workflow.maxConcurrency` 限制并发 API 调用，失败后只要调用的指纹仍一致，就从调用边界继续。
- 输入区把 TypeScript 补全、悬停、诊断和跳转定义带进 Code mode，**Dext: View APIs** 列出由 `.dext/api/dext.d.ts` 生成的 Node 与 JavaScript 参考。
- `template(input, source, values)` 按 Dext 模板渲染文本：字段由 front matter 声明，小节无法增删或重排，且不写任何文件。
- Pi 成为 Agent 后端：运行 `pi install` 安装的包、在 **Plugins** 行按会话选择、提供 `dext_fetch` 与 `dext_submit_result`，并通过 `dext_update_todos` 驱动 Plan 的 Todo 面板。
- DeepSeek Harness 桌面版通过自带启动器加 `--expose-internals` 启动，从 `presets/*.patch.yml` 列出预设，并从 `cordis.patch.yml` 合并应用内新增的模型。
- 会话历史按会话存放在 `<storageUri>/conversation-history/` 下的独立文件，截断输出写入溢出文件，过期条目会被清理。
- Resources 的每个类别都按目录分组，眼睛按钮用 `dext.hiddenSkills` 隐藏 Skill 但保留安装，MCP 工具归入 **MCP**，并搜索 `dext.mcpDirectories`、显示 MCP 图片结果。
- Skill 包可从 GitHub release 或裸仓库 URL 导入，**Update Skill pack** 报告新增与移除的 Skill，变体按 Agent 分别解析。
- 已回答的问题卡片保留全部选项、标出选中行并接受多选答案，`ui.alert` 与 `ui.form` 支持显式 `actions`。
- Plan 执行跨 Agent 回合继续，带轮次检查点与独立的最终验证，实时与还原的历史都会显示未完成、阻塞和用户中止的结果。
- 截图标注页像看图工具一样缩放：带缩放、**Fit**、**1:1**、像素尺寸和 **Hide annotations** 的工具条，图片在发送前也可以先标注。
- `git.commit` 按功能拆成一条条 Conventional Commit，`release.audit`、`release.changelog`、`release.notes` 与 `docs.sync` 随对应规则一起提供，`echo: true` 可让 Code 调用的结果显示在 Output。

## 🐛 修复

- 忽略 SIGTERM 的 stdio MCP 服务会被强制结束，MCP 清单与本会话的图片缓存都在固定预算内读取。
- 取消回合会停掉整个 CLI 进程组，已完成工具 id 的记忆也有了上限。
- 问题卡片接受多个答案，已知的选项标签也会被算作已选答案。
- VS Code 本来就用 Ctrl+C 复制的地方仍交给 VS Code，`dext.copyFilePathWithFiles` 复制的文件在资源管理器里仍可粘贴。
- 无法读取的会话文件会被跳过而不再导致激活失败，改写历史前会先重读其他窗口的写入。
- Agent 结果帧可跨桥接传输多兆字节，CLI 流累积的输出也有了上限。
- 导入 Skill 包时不再因含 NUL 字节的 JavaScript 支持文件而失败。
- 终端超时设置与运行时行为一致：默认 120,000 ms、上限 600,000 ms，非法值回落到默认值。

## 📝 其他说明

- Dext 要求 VS Code 1.106 或更新版本，默认放到次要侧边栏，同时保留用户自定义的视图位置。
- Dext 改用 MIT 许可证，`COMMERCIAL-LICENSING.md` 已删除，此前已分发的副本仍按原有条款。
- 请提交生成的 `.dext/api/dext.d.ts`、`.dext/tsconfig.json` 与 `.dext/package.json`；API 重载会把它们连同 `@types/node` 一起重写。
- `dext.history.maxOutputLength` 默认值改为 `64000`，历史只从 `dext.history*` 设置导入一次。
- 一直不返回结果的工具调用会在三十分钟后结束回合，而仍在工作的 Codex、Claude 或 Harness 回合可超过一小时。
- **Output Language** 设置同样作用于 Code mode 的 `agent()` 与 `ask()` 调用，机器可读输出永不翻译。
- 新回合的 **Process** 默认折叠，摘要保留实时 `Thinking for …` 时长与 token、命令计数，Harness 还会显示 `12k/1M context`。
