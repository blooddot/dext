# Spec Delta

## Purpose

定义 Dext 宿主与所关联 Pi CLI 版本之间的兼容边界：恢复会话前对记录工作区的预检与可读失败、模型选择失败时给出的可操作提示，以及 Pi 侧工具参数规整在 Dext 工具边界上的既定语义。

## ADDED Requirements

### Requirement: 恢复会话前校验记录的工作区
当一次回合要恢复已记录的 Pi 会话时，Dext SHALL 在启动 Pi 之前读取该会话文件首行的 `cwd`；该目录不存在时 MUST NOT 启动 Pi 进程，并 SHALL 返回说明工作区已移动或删除的错误，给出用户可执行的下一步。

#### Scenario: 记录的工作区已被改名或删除
- **WHEN** 待恢复会话的首行 `cwd` 指向的目录已被改名或删除，且该目录当时不存在
- **THEN** 该回合失败，错误文案说明会话记录的工作区已移动或删除
- **AND** 文案给出「新建会话」或在「新位置重新开始」的动作
- **AND** 不为该回合启动 Pi 进程

#### Scenario: 记录的工作区仍然存在
- **WHEN** 待恢复会话的首行 `cwd` 存在且是目录
- **THEN** 恢复按改动前的路径进行，Pi 以 `--session <path>` 启动
- **AND** 不产生工作区相关错误

### Requirement: 无法判断工作区时交回原有恢复路径
会话文件不可读、首行不是 JSON 对象、或首行没有非空的 `cwd` 时，Dext SHALL 视为无法判断并放行，MUST NOT 因此阻止恢复。

#### Scenario: 首行不可解析或缺少 cwd
- **WHEN** 会话文件是旧版本、内容损坏，或首行 `cwd` 为空字符串、缺失
- **THEN** 预检不阻止恢复，Pi 仍按原有路径启动
- **AND** 失败时报告的是 Pi 或既有会话校验给出的错误，而不是工作区错误

#### Scenario: 会话文件已在预检前校验失败
- **WHEN** 会话文件不存在或位于 Dext 会话目录之外
- **THEN** 既有「会话缺失」或「会话在 Dext 会话目录之外」的错误照常返回
- **AND** 不叠加工作区相关错误

### Requirement: 模型选择失败时提示刷新模型目录
当 `set_model` 请求失败时，Dext SHALL 在错误文案中保留 Pi 的原始失败原因，并追加一句说明模型可能已下架、需要刷新模型目录的提示。

#### Scenario: 存下的模型已不在目录中
- **WHEN** 一次回合的模型选择请求失败，原因是该 provider/modelId 已不被当前 Pi 目录提供
- **THEN** 该回合失败，文案包含 Pi 的原始失败原因
- **AND** 文案包含「模型可能已下架，请在 Configure Agent 中刷新模型目录」的提示

#### Scenario: 取消不带模型下架提示
- **WHEN** 回合在 `set_model` 等待期间被取消
- **THEN** 该回合仍以取消错误结束
- **AND** 文案不包含模型下架或刷新模型目录的提示

#### Scenario: 其它命令的错误透传不变
- **WHEN** `set_model` 之外的 RPC 命令失败
- **THEN** 错误文案与改动前一致，不追加模型下架提示

### Requirement: 工具参数以 Pi 规整后的结果为准
Dext 的工具注册 SHALL 接受 Pi 规整后的参数：可选属性的显式 `null` 被丢弃、数组参数上的单值被包成单元素数组，这两步都由 Pi 完成；Dext MUST NOT 在扩展或宿主侧再做一次 `null` 归一化或数组包装。

#### Scenario: 可选属性上的显式 null
- **WHEN** 模型对一个可选属性提交 `null`，而该属性声明不接受 `null`
- **THEN** Pi 在调用工具前丢弃该属性，宿主收到的参数里没有它
- **AND** Dext 的结果契约保持不变，不因这次调用被改写或放宽

#### Scenario: 单值被包成单元素数组
- **WHEN** 模型对一个数组参数提交单个对象而不是数组
- **THEN** Pi 在调用工具前把它包成单元素数组
- **AND** Dext 扩展按收到的数组原样转发，不再次包装
