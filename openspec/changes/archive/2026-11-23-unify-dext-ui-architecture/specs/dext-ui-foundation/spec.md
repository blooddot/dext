# Spec Delta

## Purpose

为 Dext 自有界面建立可复用的组件和宿主接入契约，使常见内容、导航、输入与反馈保持一致。用户从对话、编辑器面板或脚本入口访问同类界面时，可以依赖一致的语义和原有工作流程。

## ADDED Requirements

### Requirement: 自带界面的组件和宿主路径可追踪

Dext SHALL 记录每个自有界面的正常入口、渲染介质、共享组件或专用宿主，以及页面保有的业务职责。组件目录 SHALL 记录属性、默认值、状态、合法部件、渲染介质、可访问语义、宿主绑定和脚本开放情况。通用组件 MUST 可由各功能直接使用。

#### Scenario: 从注册入口核对覆盖

- **WHEN** 对照当前生效的侧栏、编辑器面板、预览和媒体入口及其子界面核对目录
- **THEN** 每处都有通用基础层调用路径或专用宿主适配路径
- **AND** 目录能从公开显示组件追到脚本 API 和内置页面的同一份定义，也能从公开表单追到内置交互所用的控件

#### Scenario: 三条正常入口实例使用同一部件

- **WHEN** 打开带 Plan 验收的对话回合、通过 Resources 打开一个内置 API Reference 详情，并运行多区块检查报告脚本
- **THEN** 至少一个内容组件在三个入口使用相同定义
- **AND** API Reference 的查阅动作、对话验收状态和脚本应答仍由各自的功能入口处理

### Requirement: 共用状态与可访问语义

共享组件 SHALL 为禁用、忙碌、错误、选中和空态提供明确语义。需要名字的控件 MUST 有可访问名称，状态文字 SHALL 可独立于颜色理解。复合部件 SHALL 保持合法父子结构及标签和控制对象的关联。

#### Scenario: 复合控件在各自上下文操作

- **WHEN** 用户使用键盘切换对话标签、查看资源分段、展开 Trace 并打开表单的选择列表
- **THEN** 焦点、选中和展开状态按各入口既有规则更新，标签和受控对象保持关联
- **AND** 停用项无法触发动作，空说明不会进入选项导航

#### Scenario: 动态错误和静态提示各有语义

- **WHEN** 表单校验失败，同时回放中存在一段历史错误提示
- **THEN** 实时错误按现有规则就地提示并向辅助技术报告，历史提示仍可阅读且不会触发表单行为

### Requirement: 双介质组件保持等价的内容语义

双介质组件 SHALL 对同一数据和模式保持等价的标签语义、层级、子项顺序和状态。只读回放 MUST 保留值、可访问标签及原生披露的阅读能力，并停用状态修改或只读输出中受限的动作。

#### Scenario: 回合和历史保留同一份结果

- **WHEN** 展示带 Process、Plan 验收、JSON 和结构化脚本输出的回合，再从存储中打开历史
- **THEN** 内容顺序、层级、状态文字和已有勾选值一致
- **AND** 历史验收控件为原生禁用，已答交互显示摘要，原有回合复制仍取得原始文本

### Requirement: 专用宿主保留平台生命周期

VS Code、Monaco、媒体画布及图表等专用宿主 SHALL 保留各自的焦点、主题、消息、挂载和释放契约。Dext 提供的外围导航、工具栏和反馈 SHALL 使用同一组件约定。迁移 MUST 保留已支持的键盘、滚动、拖放、草稿、复制、取消和恢复行为。

#### Scenario: 编辑与切换不丢失状态

- **WHEN** 用户在 Composer 输入内容或拖入文件，切换标签、打开弹层再取消并返回原会话
- **THEN** 草稿、引用、滚动和焦点按原流程恢复，Code 模式的 TypeScript 输入与补全按原流程工作
- **AND** 同一请求只通过既有消息路径提交一次

#### Scenario: Composer 聊天模式的文件引用与键盘行为

- **WHEN** 用户在 Composer 聊天模式输入 `@` 或在 `@` 后主动触发补全
- **THEN** 编辑器不提供文件候选，占位文字不再显示 `@ for files`
- **AND** Enter 与 Shift+Enter 沿用聊天模式的发送与换行规则
- **AND** 手写有效的 `@path` 引用、附件、拖放与粘贴沿用既有流程

#### Scenario: 编辑器标签和媒体面板按原入口工作

- **WHEN** 恢复 Resources 标签，打开预览、图像标注、视频标注或帧提取页面，再关闭相应页面
- **THEN** 资源定位、预览内容、标注保存或取消、视频时间与帧顺序保持原契约
- **AND** 原生编辑器和媒体面板依原入口获得或保留焦点，面板关闭后相应会话、监听和媒体资源完成释放

#### Scenario: 主题与布局基线

- **WHEN** 在已有浅色、深色或 VS Code 高对比度主题和受限侧栏宽度下打开相同的自带界面
- **THEN** 既有视觉默认值、焦点提示和溢出约束保持可用
- **AND** 新增可见行为可以追踪到需求及验收场景
