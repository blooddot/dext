# CHANGELOG 本版段落

用于 `release.changelog` 的整理与写作：把 `since...HEAD` 的真实变化写成 `CHANGELOG.md` 的本版段落。标题与日期由调用方生成，你只产出条目和副产物。

## 输入

- `git diff --stat` 与 `git diff` 全文：本次发布相对起点的全部改动。
- 来源一：`CHANGELOG.md` 中现有的 `## Unreleased` 段落原文。
- 来源二：`All notable changes` 引导行上方、无版本号的 `## ` 段落原文。
- 来源三：只出现在 diff 里、上面来源都未提到的变化。
- 来源四：`CHANGELOG.md` 中已存在的本版段落原文；首次生成时不存在。

四个来源合并整理，同一件事只写一次。

## 就地更新

来源四非空时，本次不是新建段落，而是更新已存在的本版段落：

- 段落标题与日期由调用方保留，你不要输出标题。
- 旧条目仍然成立就保留它的事实与反引号标识符，措辞可以按下面的预算压缩。
- 只在旧条目没写到的地方补新条目，不为同一个变化再写一条。
- diff 证明旧条目已不再成立（能力被移除、语义又变了）时改那一条；过程条目按第 4 类丢掉。
- 不要为了体现“又改了”而重排整段；旧条目不达预算时，压缩它们正是这次更新的任务。

## 预算

- `entries` 最多 60 条。超了就是失败，不是警告：先按同一页面、同一标识符、同一次重做合并，再输出。
- 每条正文不超过 200 字符（不含 `- `）。超了就砍掉第二、第三个事实，只留“什么变了 + 对他有什么影响”。
- 一条只说一件事。补充事实只写影响，不写机制；第二个 `；` 或第三个从句基本就是该砍的地方。
- 压缩不等于删结论：用户能察觉的行为、默认值、限制、破坏性改动必须留下；被砍的是实现取舍，写进 `archiveCandidates`。
- 布局、样式、内部重构这类只影响实现的变化不进 `entries`。

## 分类

每条候选内容只归一类。只有前四类进入 `entries`。

1. **净新增**：起点不存在、HEAD 存在，且用户能感知。
2. **净删除**：起点存在、HEAD 不存在。用户能感知的移除必须写入；若会打断既有用法，条目以 `**Breaking:**` 开头，并紧跟迁移动作（改哪个文件、哪个配置键、改成什么）。
3. **净改动**：两版都存在，但行为变了（默认值、语义、顺序、报错方式、界面流程）。
4. **过程条目**：本版开发期间加了又删、改了又改回去。判定：条目中的反引号标识符或文件路径，在 `since` 与 `HEAD` 两侧都不存在，或该处 diff 净变化为零。写入 `dropped`，理由一句话。
5. **决策记录**：净变化为零，但含“为什么这么做”的信息。写入 `archiveCandidates`，理由以“建议移到 PR 描述”开头。
6. **不确定**：无法从 diff 判断是否用户可感知。写入 `needsHuman`，并给一个能回答的具体问题。

`dropped` 与 `archiveCandidates` 的 `entry` 保留原文，不改写、不合并、不润色。

## 写法

- 用英文，与 `CHANGELOG.md` 现有条目一致：面向用户，说“什么变了、对他有什么影响”。
- 每条一行，动宾结构，必要时用反引号给出标识符、配置键或路径。
- 一条一个主句；第二个事实只写影响（“这样就不会……”、“现在只能在……”），不写实现。
- 不写内部实现：重构、状态机调整、变量改名、测试改动、依赖小版本升级都不写。
- 不写文件里的标题、日期、版本号；不要输出 `## ` 行。
- 同一变化只写一条，不拆成两条，不把同一条同时写进 Breaking 和普通条目。
- Breaking 条目格式固定为 `- **Breaking:** <变化>。Replace <文件或配置键> with <新用法>。`
- 只写 diff 能证明的内容；没有证据就不写。

## 输出

只输出一个 JSON 对象，不要代码围栏、解释或前后缀。字段固定为下面五个，缺一不可：

- `entries`：字符串数组，每项是一条完整的条目行，以 `- ` 开头。
- `dropped`：对象数组，每项有 `entry` 与 `reason`。
- `archiveCandidates`：对象数组，每项有 `entry` 与 `reason`。
- `needsHuman`：对象数组，每项有 `entry` 与 `question`。
- `problems`：字符串数组；只在无法完成整理时填写（例如 diff 读不出、来源互相矛盾）。非空会让调用方拒绝写入。

没有内容的数组给空数组。
